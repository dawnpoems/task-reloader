# 상세 달력 날짜 완료 기록

## 문제

- 상세보기 화면의 완료 달력은 날짜별 완료 이력 조회만 지원했다.
- 날짜를 클릭해 특정 날짜에 완료 이력을 추가하려면, 기존 완료 API가 서버 현재 시각만 사용해 선택 날짜를 반영할 수 없었다.

## 결정

- 날짜 지정 완료는 실제 완료 처리로 보고, 선택 날짜 기준으로 `completedAt`, `lastCompletedAt`, `nextDueAt`을 갱신한다.
- 상세 달력의 날짜 클릭은 이력 선택 역할을 유지하고, 선택 영역의 `이 날짜에 완료 기록하기` 버튼으로 완료를 확정한다.

## 트레이드오프

- 완료 날짜 기준으로 다음 예정일이 재계산되어 반복 작업 규칙과 일관된다.
- 과거 날짜를 잘못 찍으면 현재 스케줄이 뒤로 돌아갈 수 있으므로 미래 날짜, 시작일 이전, 마지막 완료일 이전 날짜는 막는다.

## 작업 내용

- 완료 API 요청 바디에 선택 날짜를 받을 수 있도록 `completedDate`를 추가했다.
- 백엔드 완료 처리에서 선택 날짜를 KST 기준 완료 시각으로 변환하고 기존 완료 저장/다음 예정 계산 흐름을 재사용하게 했다.
- 완료 시각은 시간까지 저장하되, 다음 예정은 완료한 날짜 기준 반복주기일의 00:00으로 계산하게 했다.
- 상세 달력 선택 날짜 영역에 날짜 지정 완료 버튼을 추가했다.
- 날짜 지정 완료 버튼 문구를 `이 날짜에 완료 기록하기`로 정리하고, 완료 이력이 없는 날짜에서만 버튼이 보이게 했다.
- 날짜 지정 완료 버튼이 카드 폭 밖으로 넘치지 않도록 액션 줄과 버튼 폭을 조정했다.
- 완료 달력에서 오늘 날짜를 바로 구분할 수 있도록 `오늘` 표시와 강조 테두리를 추가했다.
- 상세보기 기본 정보와 완료 이력의 `다음 예정`은 시간 없이 날짜만 표시하게 했다.
- 날짜 지정 완료 후 상세 정보와 완료 이력을 다시 불러오게 했다.

## 테스트 방법

- 홈 화면에서 Task 상세보기로 진입한다.
- 완료 달력에서 오늘 이후가 아닌 날짜를 선택한다.
- 오늘 날짜 칸에 `오늘` 표시가 보이는지 확인한다.
- 완료 이력이 없는 날짜에서만 `이 날짜에 완료 기록하기` 버튼이 보이는지 확인한다.
- 이미 완료 이력이 있는 날짜에서는 완료 기록 버튼이 숨겨지고 이력 목록만 보이는지 확인한다.
- `이 날짜에 완료 기록하기`를 클릭한다.
- 선택한 날짜에 완료 이력이 추가되고, 기본 정보의 최근 완료와 다음 예정이 선택 날짜 기준으로 갱신되는지 확인한다.
- 상세보기의 `다음 예정`은 시간 없이 날짜만 표시되는지 확인한다.
- 미래 날짜, 시작일 이전 날짜, 마지막 완료일 이전 날짜를 선택했을 때 완료 버튼이 비활성화되는지 확인한다.

## 관련 테스트

- `TaskServiceTest`: 날짜 지정 완료 성공, 다음 예정 날짜 단위 계산, 미래 날짜 차단, 시작일 이전 차단, 마지막 완료일 이전 차단
- `TaskServiceUserScopeTest`: 완료 처리 사용자 스코프 유지
- `TaskControllerTest`: 기존 완료 요청과 `completedDate` 포함 완료 요청
- `./gradlew :apps:api:compileJava`
- `./gradlew :apps:api:test --tests com.yegkim.task_reloader_api.task.service.TaskServiceTest --tests com.yegkim.task_reloader_api.task.controller.TaskControllerTest`
- `./gradlew :apps:api:test --tests com.yegkim.task_reloader_api.task.service.TaskServiceUserScopeTest`
- `npm run type-check`
- `npm run lint`
- `npm run build`
- 브라우저 확인: `http://127.0.0.1:5173/`에서 로그인 화면 렌더링 확인

## 확인된 제한

- `./gradlew :apps:api:test` 전체 실행은 로컬 Docker/Testcontainers 초기화 실패로 JPA/통합 테스트 5건이 시작 전에 실패했다.
- 로컬 브라우저 확인 시 백엔드 API 서버가 떠 있지 않아 상세 화면의 실제 완료 버튼 클릭은 수동 검증 대상으로 남겼다.
- 브라우저 보안 정책상 임시 HTML fixture를 열 수 없어, 상세 달력의 시각 확인은 실제 로그인/백엔드 연결 상태에서 수동으로 확인해야 한다.
