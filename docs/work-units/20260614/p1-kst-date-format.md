# KST 날짜 표시 고정

## 작업 내용

- 공통 날짜 포맷 함수가 브라우저 로컬 타임존 대신 KST 기준으로 날짜를 표시하도록 변경했다.
- 날짜/시간 포맷 모두 `Asia/Seoul` 기준으로 고정해 `00:00+09:00` 값이 해외 브라우저에서 전날로 보이는 문제를 막았다.

## 테스트 방법

- Task 상세보기에서 `다음 예정`이 KST 날짜 기준으로 표시되는지 확인한다.
- 완료 이력, 최근 완료, 인사이트 등 공통 포맷 함수를 쓰는 날짜/시간이 KST 기준으로 표시되는지 확인한다.

## 관련 테스트

- `npm run type-check`
- `npm run lint`
- `npm run build`
