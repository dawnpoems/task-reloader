# 인사이트 다음 예정 날짜 표시

## 작업 내용

- 인사이트 `개입이 필요한 작업` 목록의 `다음 예정`을 날짜만 표시하게 했다.
- 인사이트 `최근 완료한 작업` 목록의 `다음 예정`을 날짜만 표시하게 했다.
- 인사이트 `오늘 한 일` 목록의 `다음 예정`을 날짜만 표시하게 했다.
- 인사이트에서 `변경`으로 열 수 있는 편집 모달의 최근 완료 이력 `다음 예정`도 날짜만 표시하게 했다.
- 완료 시각과 `이전 예정`은 기존처럼 시간까지 표시하도록 유지했다.

## 테스트 방법

- `/insights`로 진입한다.
- `오늘 한 일`에 완료 이력이 있으면 `다음 예정`이 시간 없이 날짜만 표시되는지 확인한다.
- `최근 완료한 작업`에 이력이 있으면 `다음 예정`이 시간 없이 날짜만 표시되는지 확인한다.
- `개입이 필요한 작업`에 리스크 작업이 있으면 `다음 예정`이 시간 없이 날짜만 표시되는지 확인한다.
- `개입이 필요한 작업`에서 `변경`을 눌러 편집 모달을 열고, 최근 완료 이력의 `다음 예정`이 시간 없이 날짜만 표시되는지 확인한다.
- 같은 줄의 완료 시각, `이전 예정`, `마지막 완료`는 기존처럼 시간 표시가 유지되는지 확인한다.

## 관련 테스트

- `npm run type-check`
- `npm run lint`
- `npm run build`
