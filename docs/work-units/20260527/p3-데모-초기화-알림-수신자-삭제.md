# 데모 초기화 알림 수신자 삭제

## 작업 내용

- 데모 계정 초기화 시 등록된 이메일 알림 수신자를 모두 삭제하도록 했다.
- 데모 계정 초기화 시 이메일 알림 설정을 사용 안 함, `09:00`, `Asia/Seoul` 기준으로 되돌리도록 했다.
- 삭제된 알림 수신자 수를 데모 초기화 로그에 포함했다.
- 기존 데모 초기화 테스트 fixture에 알림 수신자와 알림 설정 repository를 연결했다.
- 데모 초기화 동작 설명에 알림 수신자 삭제와 알림 설정 초기화 내용을 추가했다.

## 테스트 방법

- 데모 계정에 알림 수신 이메일을 등록한다.
- 데모 초기화가 실행된 뒤 `/alerts` 화면에서 수신 이메일 목록이 비어 있는지 확인한다.
- 데모 초기화가 실행된 뒤 `/alerts` 화면에서 이메일 알림이 꺼지고 발송 시간이 `09:00`, 타임존이 `Asia/Seoul`인지 확인한다.
- API 로그에서 `deletedAlertRecipients` 값이 기록되는지 확인한다.

## 관련 테스트

- `./gradlew :apps:api:test`
