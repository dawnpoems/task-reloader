# 남은일정 카운트 갱신

## 작업 내용

- 홈 화면에서 남은 일정 카운트에 필요한 대시보드 요약만 별도로 불러오도록 했다.
- 작업 생성, 수정, 삭제, 완료 후 대시보드 요약도 함께 다시 불러오게 했다.
- `남은 일정 펼치기` 버튼의 숫자가 작업 변경 후 최신 값으로 갱신되게 했다.

## 테스트 방법

- 홈 화면에서 `남은 일정 펼치기 (N)` 숫자를 확인한다.
- 오늘 할 일 또는 남은 일정의 작업을 완료한다.
- 완료 후 `남은 일정 펼치기 (N)` 숫자가 바뀌는지 확인한다.
- 남은 일정이 펼쳐진 상태라면 목록도 함께 최신 상태로 갱신되는지 확인한다.

## 관련 테스트

- `npm run type-check`
