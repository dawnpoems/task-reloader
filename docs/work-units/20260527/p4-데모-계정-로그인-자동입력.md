# 데모 계정 로그인 자동입력

## 작업 내용

- 로그인 화면의 `데모 계정으로 빠르게 체험하기` 버튼을 누르면 데모 이메일과 비밀번호가 자동 입력되도록 했다.
- 버튼 클릭 시 데모 계정 안내 패널도 함께 열리게 했다.
- 기존 로그인 에러와 계정 상태 안내는 데모 계정 자동입력 시 초기화되도록 했다.

## 테스트 방법

- 로그인 화면에서 `데모 계정으로 빠르게 체험하기`를 클릭한다.
- 이메일 입력칸에 `demo@dawnpoem.kr`, 비밀번호 입력칸에 데모 비밀번호가 채워지는지 확인한다.
- 바로 로그인 버튼을 눌러 로그인할 수 있는지 확인한다.

## 관련 테스트

- `npm run type-check`
