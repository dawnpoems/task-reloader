# 메일 링크 로그인 이메일 자동입력

## 작업 내용

- 작업 마감 알림 메일의 확인 링크와 작업 링크에 로그인 아이디 이메일을 `email` query로 포함했다.
- 로그인 아이디가 링크에 반영되도록 메일 본문을 수신자마다 렌더링하게 바꿨다.
- 로그인 화면은 URL의 `email` query를 읽어 이메일 입력칸 초기값으로 사용한다.
- 비로그인 상태에서 메일의 홈/작업 링크로 들어와 로그인 화면으로 이동해도 `email` query가 유지되게 했다.

## 테스트 방법

- `http://localhost:5173/auth/login?email=test%40example.com`을 열어 이메일 입력칸이 자동으로 채워지는지 확인한다.
- 비로그인 상태에서 `http://localhost:5173/tasks/1?email=test%40example.com`으로 들어가 로그인 화면의 이메일 입력칸이 채워지는지 확인한다.
- 실제 메일 또는 Mailpit에서 확인 링크와 작업 링크에 `email=` query가 붙는지 확인한다.

## 관련 테스트

- `./gradlew :apps:api:compileJava`
