# 상세 완료기록 삭제

## 문제

- 상세보기 완료 달력에서 날짜별 완료 이력을 확인하고 추가할 수 있지만, 잘못 기록한 완료 이력을 삭제할 방법이 없었다.
- 최신 완료 이력을 삭제할 때 Task의 현재 `completedAt`, `lastCompletedAt`, `nextDueAt`이 그대로 남으면 실제 완료 이력과 현재 일정이 불일치한다.

## 결정

- 완료 기록 삭제 후 현재 Task 일정도 남아 있는 최신 완료 이력 기준으로 재계산한다.
- 남은 완료 이력이 없으면 최근 완료 값은 비우고, 다음 예정일은 시작일 기준으로 되돌린다.
- 삭제 전 브라우저 확인창으로 사용자가 실제 삭제 의사를 한 번 더 확인한다.

## 작업 내용

- `DELETE /api/tasks/{taskId}/completions/{completionId}` API를 추가했다.
- 완료 이력 삭제 후 Task의 현재 완료/다음 예정 상태를 복구하는 도메인 로직을 추가했다.
- 상세보기 완료 달력에서 완료 이력이 있는 날짜를 선택하면 `완료기록 삭제하기` 버튼이 보이도록 했다.
- 삭제 버튼 클릭 시 확인창을 띄우고, 삭제 성공 후 상세 정보와 완료 이력을 다시 불러오게 했다.
- 모바일에서는 `완료기록 삭제하기` 버튼을 `이 날짜에 완료 기록하기` 버튼과 같은 폭/높이 기준으로 키웠다.

## 테스트 방법

- 홈 화면에서 Task 상세보기로 진입한다.
- 완료 이력이 있는 날짜를 클릭한다.
- 완료 이력 항목에 `완료기록 삭제하기` 버튼이 보이는지 확인한다.
- 버튼을 클릭하고 확인창에서 취소를 누르면 완료 이력이 그대로 남는지 확인한다.
- 다시 버튼을 클릭하고 확인을 누르면 선택한 완료 이력이 사라지는지 확인한다.
- 삭제한 기록이 최신 완료였으면 기본 정보의 최근 완료/다음 예정이 남은 최신 완료 기준으로 바뀌는지 확인한다.
- 모든 완료 이력을 삭제한 경우 최근 완료가 비워지고 다음 예정이 시작일로 돌아가는지 확인한다.
- 모바일 폭에서 `완료기록 삭제하기` 버튼이 완료 기록 카드 너비에 맞게 크게 보이고 쉽게 누를 수 있는지 확인한다.
