# 인사이트 오늘 한 일 및 위험 신호 개편

## 작업 내용

- 인사이트 페이지 상단에 `오늘 한 일` 요약 영역을 추가했다.
- 오늘 완료 개수, 오늘 예정 작업 처리 수, 밀린 작업 해소 수를 기준으로 짧은 해석 문구를 표시한다.
- 오늘 완료한 최근 작업 목록에서 작업 상세로 바로 이동할 수 있게 했다.
- 기존 대시보드식 전체 요약과 최근 완료 섹션을 제거하고, 인사이트 본문은 `확인할 신호` 중심으로 재구성했다.
- 리스크 작업에는 7일 이상 지연, 30일 무완료 이유와 확인이 필요한 이유를 함께 표시한다.

## 테스트 방법

- `/insights`로 진입한다.
- 오늘 완료한 작업이 있는 계정에서는 상단 `오늘 한 일`의 완료 수와 완료 작업 목록이 표시되는지 확인한다.
- 오늘 예정이었던 작업을 완료한 경우 `오늘 예정 작업 N개 처리` 문구가 표시되는지 확인한다.
- 기한이 지난 작업을 오늘 완료한 경우 `밀려 있던 작업 N개 해소` 문구가 표시되는지 확인한다.
- 7일 이상 지연되었거나 30일간 완료 이력이 없는 작업이 있으면 `확인할 신호`에 리스크 카드와 사유 칩이 표시되는지 확인한다.
- 리스크 작업명 또는 오늘 완료 작업명을 눌렀을 때 해당 작업 상세 화면으로 이동하는지 확인한다.

## 관련 테스트

- 이번 작업은 화면 구성 변경이라 프론트 타입 체크와 빌드로 기본 검증한다.
