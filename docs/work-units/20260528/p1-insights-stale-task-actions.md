# 인사이트 무완료 작업 변경 및 삭제 액션

## 작업 내용

- 인사이트 `개입이 필요한 작업` 목록에서 `30일 무완료` 리스크 작업에만 `변경`/`삭제` 버튼을 노출했다.
- `변경` 버튼은 작업 단건 조회 후 기존 Task 수정 모달을 열도록 연결했다.
- `삭제` 버튼은 확인창 후 기존 Task 삭제 흐름을 재사용하도록 연결했다.
- 삭제 중인 리스크 카드의 액션 버튼을 비활성화하고 `삭제 중...` 문구를 표시한다.

## 테스트 방법

- `/insights`로 진입한다.
- `30일 무완료` 사유가 있는 작업 카드에 `변경`/`삭제` 버튼이 보이는지 확인한다.
- `7일 이상 지연`만 있는 작업에는 `변경`/`삭제` 버튼이 보이지 않는지 확인한다.
- `변경`을 누르면 기존 Task 수정 모달이 열리고 저장/취소가 동작하는지 확인한다.
- `삭제`를 누른 뒤 확인창에서 취소하면 작업이 유지되는지 확인한다.
- `삭제`를 확인하면 작업이 삭제되고 인사이트 목록에서 사라지는지 확인한다.

## 관련 테스트

- 별도 프론트 테스트 러너가 없는 범위라 타입 체크와 프로덕션 빌드로 검증한다.
