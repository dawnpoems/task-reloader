# 반복 주기 입력 앞자리 0 정리

## 작업 내용

- 새 Task 추가 모달의 반복 주기 입력값을 문자열 상태로 관리하도록 변경했다.
- Task 수정 모달에도 같은 입력 정규화 로직을 적용했다.
- 반복 주기 입력 중 빈 값은 그대로 유지하고, `05`, `0012`처럼 앞자리에 붙은 0은 즉시 제거하도록 공통 유틸을 추가했다.
- 저장 시점에만 반복 주기를 정수로 변환하고, 1일 미만 값은 기존 오류 문구로 막는다.

## 테스트 방법

- 홈 화면에서 `새 Task 추가`를 눌러 새 Task 추가 모달로 진입한다.
- 반복 주기 값을 모두 지운 뒤 `5`를 입력했을 때 앞에 `0`이 붙지 않고 `5`만 보이는지 확인한다.
- 반복 주기 값에 `05`, `0012`를 입력했을 때 각각 `5`, `12`로 정리되는지 확인한다.
- 반복 주기 값에 `0`을 입력하고 저장했을 때 `반복 주기는 1일 이상이어야 합니다.` 오류가 표시되는지 확인한다.
- 기존 Task의 수정 모달에서도 같은 값을 입력해 동일하게 동작하는지 확인한다.
