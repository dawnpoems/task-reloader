# 작업 단위: 메일 템플릿 홈 링크와 섹션 강조

## 문제
- 작업 마감 이메일에서 앱으로 바로 이동할 수 있는 대표 링크가 필요하다.
- 오늘 마감과 지난 작업의 갯수와 목록이 떨어져 보여 한눈에 묶어 읽기 어렵다.
- `확인하러가기` 버튼과 섹션 헤더가 충분히 눈에 띄지 않아 메일에서 주요 행동과 구분 정보가 약하게 보인다.

## 결정
- 메일 상단에 `확인하러가기` 버튼을 추가하고 앱 홈 주소로 연결한다.
- `확인하러가기` 버튼은 카드 폭을 채우는 블록형 버튼으로 만들고 진한 파란색 계열로 강조한다.
- 오늘 마감과 지난 작업을 각각 카드형 섹션으로 구성해 갯수 바로 아래에 해당 작업 목록이 나오게 한다.
- 오늘 마감 섹션은 초록 계열, 지난 작업 섹션은 빨강 계열로 구분한다.
- plain text 본문에도 앱 홈 링크를 함께 넣는다.

## 트레이드오프
- 장점: 메일에서 바로 홈페이지로 이동할 수 있고, 섹션별 작업 목록과 상태 구분을 더 직관적으로 확인할 수 있다.
- 단점: HTML 템플릿 구조가 기존 요약 박스 방식보다 조금 길어지고, 일부 메일 클라이언트에서 색감이 조금 다르게 보일 수 있다.

## 구현 요약
- 템플릿 렌더러에 앱 홈 주소 변수 추가
- HTML 메일 템플릿에 `확인하러가기` 버튼 추가
- `확인하러가기` 버튼을 전체 폭 블록 버튼과 파란색 계열로 변경
- 오늘 마감/지난 작업을 갯수와 목록이 붙은 섹션 구조로 변경
- 오늘 마감 섹션의 테두리와 헤더 배경을 초록 계열로 변경
- 지난 작업 섹션의 테두리와 헤더 배경을 빨강 계열로 변경
- plain text 메일 템플릿에 앱 홈 링크 추가
- 렌더러 테스트에 앱 홈 링크 검증 추가

## 테스트 방법
- 메일 템플릿 렌더링 테스트에서 HTML/plain text 본문에 앱 홈 링크가 포함되는지 확인한다.
- 메일 템플릿 렌더링 테스트로 HTML 템플릿 처리가 정상인지 확인한다.
- 전체 API 테스트로 기존 메일 발송/알림/작업 기능 회귀 여부를 확인한다.
