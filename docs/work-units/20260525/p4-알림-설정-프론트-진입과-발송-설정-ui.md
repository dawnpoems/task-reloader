# 작업 단위: 알림 설정 프론트 진입과 발송 설정 UI

## 작업 내용
- 알림 설정 응답/수정 요청 타입 추가
- 수신 이메일 응답/추가 요청 타입 추가
- 알림 설정 조회/수정 API 함수 추가
- 수신 이메일 목록/추가/삭제 API 함수 추가
- 공용 타입 export에 알림 설정 타입 추가
- `/alerts` 라우트 추가
- 상단 네비게이션에 알림 설정 진입 버튼 추가
- 알림 설정 페이지 컴포넌트 추가
- 설정 조회, 수신 이메일 조회, 로딩, 에러 재시도, 빈 상태 표시 추가
- 알림 사용 여부 토글 UI 추가
- 발송 시간 입력 UI 추가
- 타임존 입력과 추천 목록 추가
- 설정 저장/되돌리기 버튼 추가
- 저장 성공/실패 메시지 표시 추가
- 알림 설정 페이지 스타일과 모바일 반응형 처리 추가
- 프론트 work unit 작성 기준을 작업 규칙에 반영

## 테스트 방법
- 프론트 타입 체크로 신규 타입, API client, 라우트, 컴포넌트 연결이 빌드 가능한지 확인한다.
- 로컬 API와 웹 서버를 띄운 뒤 로그인한다.
- 상단 `알림 설정` 버튼으로 `/alerts` 이동을 확인한다.
- 현재 알림 설정과 수신 이메일 목록이 표시되는지 확인한다.
- 알림 사용 여부, 발송 시간, 타임존을 변경한다.
- `발송 설정 저장`을 눌러 성공 메시지와 현재 설정 카드 값이 갱신되는지 확인한다.
- 잘못된 타임존 값을 입력하면 백엔드 에러 메시지가 표시되는지 확인한다.

## 관련 테스트
- 자동화 테스트 없음
