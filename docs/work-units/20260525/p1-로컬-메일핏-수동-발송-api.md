# 작업 단위: 로컬 메일핏 수동 발송 API

## 문제
- 로컬에서 Mailpit으로 메일 템플릿을 눈으로 확인하려면 실제 발송 로직을 호출할 진입점이 필요하다.
- 운영용 스케줄러가 아직 붙기 전이라도 현재 사용자 기준의 작업 마감 이메일을 즉시 발송해볼 수 있어야 한다.

## 결정
- `local` 프로필에서만 동작하는 수동 발송 API를 추가한다.
- 현재 로그인 사용자 기준으로 알림 설정, 수신자, 오늘 마감/지난 작업 집계를 조회한 뒤 메일 발송 서비스를 호출한다.
- 응답에는 발송 수, 수신자 수, 집계 수, 스킵 사유를 포함한다.

## 트레이드오프
- 장점: 운영 스케줄러를 기다리지 않고 Mailpit에서 제목/본문/수신자 렌더링을 확인할 수 있다.
- 단점: 개발용 API이므로 운영 프로필에 노출되지 않도록 프로필 제한을 유지해야 한다.

## 구현 요약
- 로컬 전용 수동 발송 컨트롤러 추가
- 로컬 전용 수동 발송 서비스 추가
- 수동 발송 결과 응답 DTO 추가
- 수신자 없음 또는 발송 대상 작업 0건이면 발송하지 않고 스킵 사유를 반환

## 테스트 방법
- 컴파일로 신규 컨트롤러/서비스/DTO가 빌드 가능한지 확인한다.
- 로컬 프로필에서 API를 실행한 뒤 Mailpit 웹 UI에서 수신 메일을 확인한다.

## 관련 테스트
- 자동화 테스트 추가 없음 (이번 단계는 구현 코드만 진행)

## 한 줄 요약
- 로컬 개발 환경에서 작업 마감 이메일 알림을 즉시 발송해 Mailpit으로 확인할 수 있는 API를 추가했다.
