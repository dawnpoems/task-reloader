# Work Unit: p5-main-readme-endpoints-insights-refresh

## 문제

메인 README의 주요 엔드포인트와 인사이트 지표 설명이 현재 구현보다 축약되어 있었다.

인증/관리자/알림 API와 인사이트 하위 엔드포인트가 빠져 있었고, 인사이트 지표도 최신 위험 신호와 추세 필드를 충분히 설명하지 못했다.

## 결정

README 전체 정리까지 포함하는 방향으로 최신화했다.

## 트레이드오프

엔드포인트 표만 고치는 것보다 변경 범위는 커졌지만, 포트폴리오 문서로 읽을 때 현재 제품 기능과 운영 상태를 한 번에 파악할 수 있게 했다.

## 작업 내용

- 개요, 문제의식, 해결방안, 결과, 한계와 다음 단계 문구를 현재 기능 기준으로 갱신
- 인증, Task, 인사이트, 이메일 알림, 관리자 API 엔드포인트 표 추가
- `dashboard`, `overview` 인사이트 지표 정의와 `riskyTasks`, `top*Trends` 필드 설명 추가
- 관측성 엔드포인트와 확장 계획을 최신 운영/부하테스트 상태에 맞춰 정리

## 테스트 방법

- README의 엔드포인트 표를 실제 컨트롤러 매핑과 대조
- README의 인사이트 지표 정의를 API DTO와 서비스 계산 로직과 대조
- 문서 diff에 markdown 표 깨짐이나 trailing whitespace가 없는지 확인

## 관련 테스트

- 문서 변경이라 런타임 테스트는 추가하지 않음
- `git diff --check`
